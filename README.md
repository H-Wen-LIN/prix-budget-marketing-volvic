# Projet Volvic « Soutien Collagène » : prix et budget marketing

Dossier de groupe sur le lancement d'une gamme d'eau Volvic enrichie en nutriments vegan qui aident l'organisme à produire son collagène.

## Le site

- **`index.html`** : page 1 du dossier, « Le marché ». Elle contient :
  - la délimitation du marché ;
  - les 3 cercles de concurrents, avec pour chacun ses tarifs, sa santé financière, ses investissements et sa stratégie ;
  - la carte prix / qualité interactive ;
  - la liste de toutes les sources.
- `le-marche.html` : même page, dans le format utilisé pour l'artifact Claude.
- `carte-perceptuelle-concurrents-directs.html` : la carte seule, sans le reste de la page.

Pour voir le site : ouvrir `index.html` dans un navigateur, ou activer GitHub Pages (voir plus bas).

## Les documents de travail

- `analyse-concurrentielle-volvic-soutien-collagene.md` : l'analyse des 3 cercles de concurrents.
- `sources-donnees-volvic.md` : le dossier de sources, rangé selon la méthode du cours (tarifs, santé financière, investissements et stratégie, intérêt du public).
- `data/google-trends-fr-2021-2026.csv` : les données Google Trends brutes.
- `images/` : l'infographie des 3 cercles et la page qui sert à la générer.

## Mettre le site en ligne avec GitHub Pages

1. Ouvrir **Settings → Pages** sur GitHub.
2. Dans « Build and deployment », choisir **Deploy from a branch**.
3. Choisir la branche `main` et le dossier `/ (root)`, puis cliquer sur **Save**.
4. Après une ou deux minutes, le site est en ligne à l'adresse https://h-wen-lin.github.io/prix-budget-marketing-volvic/

Remarque : GitHub Pages rend le site public si le dépôt est public. Sur un compte gratuit, Pages ne fonctionne pas sur un dépôt privé.
